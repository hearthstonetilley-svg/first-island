## Core and ownership

Playback speed and pause now belong to worker scheduling, outside authoritative world state and the append-only event log. Live dial changes are validated world interventions, logged once at the current fixed tick. Initialization creates a tick-zero generation event for one seed/dial run; the worker rejects a second init. Snapshot/export, entry gating, camera and selection do not mutate the world. A worker-handler test exercises the actual renderer message path, including rejected messages and repeated init.

Version-2 run exports contain a detached final-state verification checkpoint. Replay initializes a new simulation from seed and initial dials, advances fixed ticks and applies only the recorded interventions at their original ticks. It verifies every regenerated event and the rebuilt full state, never hydrating from the checkpoint. The state includes terrain, trees, food, needs, PRNG state, ID allocation, private movement/decision/cooldown data and fractional generation progress. Version-1 artifacts require their original source version.

The simulation owns tree descriptions with stable IDs and explicit food links. Snapshots include trees and plants. The renderer no longer reads startup world.trees: persistent instanced templates consume subsequent snapshots, updating transforms/counts and supporting removal or kind changes. One additional instanced group draws small fruit stock cues from plant quantity/capacity and nutrition: consumption shrinks them, depletion or zero nutrition hides them, and regrowth restores them. No renderer-owned food or regrowth clock. Terrain, canopy templates and all biological thresholds/rates are unchanged.
